# 0001. Record architecture decisions

Date: 2026-11-12 · Status: accepted

## Context
The handoff (docs/handoff/README.md, "Engineering decision defaults") asks that
any unspecified detail be settled with the simpler reversible option and logged.

## Decision
Keep short, numbered records in `docs/decisions/NNNN-title.md` with Context,
Decision and Consequences. A later record supersedes an earlier one by number;
records are not edited after acceptance except to mark them superseded.

## Consequences
Reviewers can see why a choice was made without reading PR history.
